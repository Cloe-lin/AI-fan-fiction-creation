> **完整版快照：** Git 标签 `v0.7-full`  
> **配图：** 可将截图放入 [`docs/images/`](images/)（与 personal 共用命名规范见 [`images/README.md`](images/README.md)）

## 一、完整版与个人版的区别

| | 完整版 | 个人版 |
|--|--------|--------|
| 目录 | `aitongrenwen` | `aitongrenwen-personal` |
| 登录 | **需要**（admin / user01–user20） | 免登录 |
| 书库 | 公共 + 私人 | 仅本机私人 |
| 适用 | 内测、演示、面试 | 自己私密创作 |

**若只需自己用：** 优先看个人版教程，步骤更简单。

## 二、环境要求

- Python **3.11+**
- Windows / macOS / Linux
- LLM API（DeepSeek 等）+ Embedding（豆包 API 或本地 BGE）
- 浏览器通过 **http://127.0.0.1:8010/** 访问（勿用 file://）

```powershell
python --version
```

## 三、部署步骤

### 1. 进入后端并安装依赖

```powershell
cd "d:\intellij project\aitongrenwen\backend"
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
```

![安装依赖](images/02-venv-install.png)

### 2. 配置 `.env`

```powershell
copy .env.example .env
notepad .env
```

```env
# 完整版不要设 PERSONAL_MODE，或设为 false

LLM_API_KEY=你的密钥
LLM_BASE_URL=https://api.deepseek.com/v1
LLM_MODEL=deepseek-chat
LLM_REVIEW_MODEL=deepseek-chat

EMBEDDING_PROVIDER=doubao
EMBEDDING_API_KEY=...
EMBEDDING_MODEL=ep-...
EMBEDDING_BASE_URL=https://ark.cn-beijing.volces.com/api/v3

JWT_SECRET=请改成随机长字符串
```

![.env 配置（Key 打码）](images/03-env-config.png)

### 3. 预置登录账号

首次启动会自动 seed；也可手动：

```powershell
.\venv\Scripts\python scripts\seed_users.py
```

密码写入：`backend/app/data/credentials_initial.txt`（**勿提交 Git**）

| 账号 | 说明 |
|------|------|
| `admin` | 管理员：公共书库上传、查看全部存档 |
| `user01`–`user20` | 普通用户：私人书库 + 本人存档 |

### 4. RAG 入库（可选但推荐）

```powershell
# 确保 modaozuoshi/text/ 下有 txt
.\venv\Scripts\python scripts\setup_rag.py --novel modaozuoshi
```

### 5. 启动服务

```powershell
.\venv\Scripts\python.exe -m uvicorn app.main:app --reload --port 8010
```

![启动成功](images/04-start-server.png)

### 6. 浏览器访问

```text
http://127.0.0.1:8010/
```

![登录页](images/05-browser-login.png)

使用 `credentials_initial.txt` 中的账号密码登录。

## 四、功能 walkthrough

### 4.1 普通用户（user01）

1. 登录 → 选书 → 勾选人物 → 写设定 → 生成  
2. 存档仅**自己可见**  
3. 上传 txt → 只能入**私人书库**

![创作界面](images/06-select-novel.png)

### 4.2 管理员（admin）

- 上传时可选择 **公共书库**（全员可见）  
- 可编辑公共书人物深档  
- 可查看他人存档（排障用）

### 4.3 人物档案编辑

人物卡片 → **「档案」** → 保存（权限：私人书主人 / 公共书管理员）

![档案编辑](images/09-profile-edit.png)

## 五、账号与数据

| 文件 | 说明 |
|------|------|
| `backend/app/data/auth.db` | 用户库（哈希密码） |
| `backend/app/data/credentials_initial.txt` | 初始明文密码（仅本地） |
| `backend/app/data/stories/` | 存档（含 `owner_id`） |
| `backend/.env` | API Key，勿泄露 |

重置全部预置密码：

```powershell
.\venv\Scripts\python scripts\seed_users.py --force
```

## 六、常见问题

| 问题 | 处理 |
|------|------|
| 登录没反应 | 必须用 `http://127.0.0.1:8010/`，检查后端是否启动 |
| 402 余额不足 | DeepSeek 等平台充值 |
| 403 私人书无权 | 换对应 owner 账号或 admin |
| 端口占用 | `--port 8011` 或关闭旧进程 |

更多通用问题见个人版教程第七节。
