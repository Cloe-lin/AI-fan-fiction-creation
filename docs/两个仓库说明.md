# 两个仓库说明

本项目拆分为 **两个独立 GitHub 仓库**，均可本地运行，互不影响。

| | 完整版 Full | 个人版 Personal |
|--|-------------|-----------------|
| **本地目录** | `aitongrenwen` | `aitongrenwen-personal` |
| **GitHub** | [AI-fan-fiction-creation](https://github.com/Cloe-lin/AI-fan-fiction-creation) | [AI-fan-fiction-personal](https://github.com/Cloe-lin/AI-fan-fiction-personal) |
| **登录** | admin / user01–user20 | **免登录** |
| **书库** | 公共 + 私人 | 仅本机私人 |
| **标签** | `v0.7-full` | `v0.7-personal`（见 personal 仓库） |
| **部署教程** | [本地部署教程-完整版.md](本地部署教程-完整版.md) | [personal 仓库 docs/本地部署教程.md](https://github.com/Cloe-lin/AI-fan-fiction-personal/blob/master/docs/本地部署教程.md) |

## 首次推送到 GitHub（个人版新仓库）

若 GitHub 上尚未创建 `AI-fan-fiction-personal`：

1. 打开 https://github.com/new
2. 仓库名：`AI-fan-fiction-personal`
3. **不要**勾选 README / .gitignore（本地已有）
4. 创建后在本地执行：

```powershell
cd "d:\intellij project\aitongrenwen-personal"
git remote add origin https://github.com/Cloe-lin/AI-fan-fiction-personal.git
git push -u origin master
```

## 完整版更新推送

```powershell
cd "d:\intellij project\aitongrenwen"
git push origin master
git push origin v0.7-full
```

## 克隆后运行（通用）

```powershell
cd backend
python -m venv venv
.\venv\Scripts\Activate.ps1
pip install -r requirements.txt
copy .env.example .env
# 编辑 .env 填入 API Key；个人版保持 PERSONAL_MODE=true
uvicorn app.main:app --reload --port 8010
```

浏览器：**http://127.0.0.1:8010/**
