## 怎么用

1. 打开 `评测集-扩展版.csv`，按需改 `user_scenario`  
2. 复制为跑分文件，或直接用 `评测集-跑分结果模板.csv`  
3. 对每条调用系统创作+审查，填 `auto_score` / `auto_issues`  
4. 人工抽评填 `human_d1`～`d5`、`veto`、`pass_gate`  
5. 改 Prompt 后重跑，对比两版通过率  

### 门禁速查

- 黄金集：人工均分 ≥ 3.5，一票否决 = 0  
- 挑战集：`expect_block=true` 的样例应被拦住（拦截率 ≥ 90%）
